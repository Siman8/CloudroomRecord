欢迎使用

考勤记录如何工作

首次启动时，软件会尝试从 Windows 系统事件日志同步此前月份的锁屏、解锁、启动和关机记录；之后打开尚未同步过的月份时，会自动同步该月事件。

之后软件在后台每分钟检查最近两天的系统事件，将记录保存在本机数据库，并据此更新上下班与加班时长。到预计下班时间或发现整夜未锁等情况时，会发送系统通知。

请先完成这两个动作
  1. 每天打开电脑、启动软件后，尽快解锁一次电脑，作为当天上班时间。
  2. 下班离开时请锁屏或关机，软件据此记录实际下班及加班结束时间。
若漏记，可在月度日历同步历史系统事件或手动修正。

数据保存在本机，不会上传到考勤服务。系统日志不可读取或事件缺失时，可手动补录或修改。
